# Gestion de projet — DETOUR

## 1. Présentation

DETOUR est un projet de plateforme d'agence de voyage permettant de présenter des destinations et de gérer les demandes de voyage des clients.

Le projet comprend notamment un site  et un espace de gestion destiné aux gestionnaires de l'agence.

## 2. Outils de gestion de projet

Pour organiser le développement, nous avons utilisé les outils suivants :

- **GitHub** : hébergement du code source et suivi des modifications.
- **GitHub Issues** : création et suivi des tâches et des problèmes à résoudre.

## 3. Organisation du travail

L'organisation du projet DETOUR s'est appuyée sur un document PDF servant de référence pour le projet, ainsi que sur les GitHub Issues pour structurer et suivre les tâches à réaliser.

Document PDF : utilisé comme support de référence pour consulter les informations et les consignes du projet.
GitHub Issues : utilisées pour identifier, décrire et suivre les tâches ainsi que les différents points à traiter au cours du développement.
Git et GitHub : utilisés pour versionner le code source et conserver l'historique des modifications.

Cette organisation a permis de centraliser les informations du projet, de suivre les tâches identifiées et de conserver une trace des évolutions du code.
## 4. Suivi des fonctionnalités

Les principales fonctionnalités travaillées comprennent :

- La présentation des destinations.
- La gestion des demandes de voyage.
- L'affichage et le suivi des informations clients.
- L'espace de gestion destiné aux gestionnaires.
- L'authentification des gestionnaires.


## 5. Gestion du code source

Le code est versionné avec Git et hébergé sur GitHub.

**Dépôt du projet :** https://github.com/ALEXIAAAA794/detour-travel-agency
